# Movies Review App
* A simple movie review application built using Node.js, Express, and EJS.
Users can view movies, post reviews, rate movies.

# Features
## Movie Display

* View a list of available movies
* Detailed movie pages with title, description, and release year
* Automatic average rating calculation based on submitted reviews

## Review System

* Logged-in users can submit one review per movie
* Reviews include:
* Username
* Rating (1–5)
* Commen

## User Interface

* Dark theme with accent colors
* Clean layout and responsive design
